#Student Performance Prediction System

#Project Title
Student Performance Prediction System using Machine Learning

---

#Description
This project is a Machine Learning-based web application that predicts whether a student will pass or fail based on academic factors such as study hours, attendance, and previous scores. The model is trained using supervised learning techniques and deployed using Streamlit for an interactive user interface.

---

#Features
- Data preprocessing using Pandas
- Exploratory Data Analysis (EDA)
- Machine Learning model training
- Model evaluation and accuracy check
- Prediction of student performance (Pass/Fail)
- Interactive Streamlit web application
- Model saved using Joblib for reuse

---

#Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib / Seaborn
- Streamlit
- Joblib

---

#Dataset Info
The dataset contains the following features:

- "study_hours" → Number of hours a student studies
- "attendance" → Percentage of attendance
- "previous_score" → Marks obtained in previous exams
- "result" → Target variable (0 = Fail, 1 = Pass)
